robot_slam
=========

This package provides two stage-specific launches for mapping and localization using Nav2 and SLAM Toolbox.

**Prerequisites**

- ROS 2 (Humble or Jazzy). Ensure `$ROS_DISTRO` is set to your ROS 2 distribution.
- Typical Nav2 and SLAM Toolbox packages installed (these are listed in package.xml).

**Quick workspace helpers**

A small helper script is included at the workspace root to make sourcing and building easier: [source_ros2.sh](../..//source_ros2.sh)

- Source the workspace (from workspace root):

```bash
source ./source_ros2.sh
source_ros2
```

- Build the workspace (from workspace root):

```bash
# build everything
build_ros2
# or build only this package
build_ros2_pkg robot_slam
```

If you prefer manual commands:

```bash
source /opt/ros/$ROS_DISTRO/setup.bash
colcon build --symlink-install
source install/setup.bash
```

**Launch files**

- Stage 1 (Mapping): [launch/slam.launch.py](launch/slam.launch.py)

  Starts robot description, local EKF, SLAM Toolbox (online async), Nav2 servers, lifecycle manager and RViz configured for mapping. Run:

  ```bash
  ros2 launch robot_slam slam.launch.py
  ```

  Optional overrides:

  ```bash
  ros2 launch robot_slam slam.launch.py slam_params_file:=/path/to/slam_toolbox.yaml rviz_config:=/path/to/mapping.rviz
  ```

- Stage 2 (Localization & Navigation): [launch/localization.launch.py](launch/localization.launch.py)

  Starts robot description, local EKF, AMCL, map_server, the Nav2 navigation stack, lifecycle manager and RViz with Set Initial Pose / Set Goal tools. Run (example):

  ```bash
  ros2 launch robot_slam localization.launch.py map_yaml:=/absolute/path/to/your_map.yaml
  ```

  If you don't supply `map_yaml` it defaults to a sample map provided by `ucsd_robocar_nav2_pkg` (declared as a dependency).

**RViz layouts**

- Mapping layout: `rviz/mapping.rviz`
- Localization layout: `rviz/localization.rviz`

**Notes and tips**

- The Stage 2 launch expects a saved map (YAML + PGM). Point `map_yaml` to the YAML file generated by `slam_toolbox` or another mapper.
- Use RViz's "2D Pose" tool to set the robot's initial pose (`/initialpose`) and the "2D Nav Goal" tool to send goals (`/goal_pose`).
- SLAM Toolbox config namespace was adjusted to be compatible with the standard launch files (see `config/slam_toolbox.yaml`).

If you want, I can add a packaged sample map into this package so Stage 2 can run without depending on the hub package.
